# ENAS HAJI — موقع + نظام الحجوزات ولوحة التحكم

هذا الإصدار يحافظ على واجهة ENAS HAJI الوردية/السوداء والشعار ومعلومات التواصل، مع **نظام طلبات حقيقي** (Backend) قابل للتشغيل: تخزين آمن نسبيًا في SQLite، لوحة تحكم بكلمة مرور، حالات الطلبات، البحث، تصدير CSV، زر واتساب، وإمكانية وصول تنبيهات بريد إلكتروني.

## 1) المتطلبات
- جهاز به Python 3.10 أو أحدث.
- استضافة لتشغيل Python عند الإطلاق العام؛ تشغيل الملف `index.html` وحده لا يحفظ الطلبات.

## 2) التشغيل محليًا (Windows)
افتح Terminal داخل مجلد المشروع، ثم نفّذ:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python setup.py
uvicorn app:app --reload
```

على Mac/Linux استبدل التفعيل بـ `source .venv/bin/activate` ويمكن تشغيل `python3` بدلاً من `py`.

**عند تشغيل `setup.py`** ستختار بريد الإدارة وكلمة مرور مكونة من 12 حرفًا على الأقل. البرنامج ينشئ `.env` ويخزن تجزئة كلمة المرور؛ لا تشارك هذا الملف.

- الموقع: **http://127.0.0.1:8000/**
- لوحة التحكم: **http://127.0.0.1:8000/admin**
- صفحة تسجيل الدخول: http://127.0.0.1:8000/admin/login

## 3) كيف يسير الطلب؟
1. العميلة تملأ النموذج في الموقع.
2. يرسل المتصفح البيانات إلى `POST /api/bookings` على **السيرفر نفسه**.
3. التحقق من الاسم، الهاتف، الخدمة، الحد الأقصى للطول وبعض حماية الإغراق.
4. يُحفظ الطلب في قاعدة `data/bookings.sqlite3` مع رقم EH-000001 مثلاً.
5. العميلة ترى رسالة نجاح ورقم طلبها. **الطلب ليس موعدًا مؤكدًا.**
6. الإدارة تراجع الطلب من `/admin` وتغير حالته أو تراسل العميلة من زر واتساب.
7. عند تفعيل SMTP، يُرسل تنبيه بريد تلقائيًا. إرسال البريد لا يحل محل الحفظ في قاعدة البيانات.

## 4) تفعيل البريد الإلكتروني (اختياري)
بعد الإعداد، افتح `.env` وعدل هذه المفاتيح بقيم حقيقية من مزود البريد الخاص بك:

```env
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=alerts@example.com
SMTP_PASSWORD=APP_PASSWORD_FROM_PROVIDER
SMTP_FROM=alerts@example.com
SMTP_USE_SSL=false
SMTP_USE_STARTTLS=true
NOTIFY_EMAIL=owner@example.com
PUBLIC_SITE_URL=https://your-domain.example
```

الأمثلة **قيم توضيحية وليست بيانات حقيقية**. قد يحتاج مزود البريد إلى كلمة مرور تطبيق أو خدمة بريد معاملات. أعد تشغيل السيرفر بعد تعديل `.env`. عندما تكون إعدادات البريد فارغة، يظل الحفظ في قاعدة البيانات يعمل، لكن لا تُرسل رسائل بريد. عند فشل البريد، يحتفظ النظام بالطلب ويرصد الخطأ في سجل الخادم.

## 5) نشر الموقع الحقيقي
- انشر هذا المشروع على خادم Python يدعم FastAPI/Uvicorn.
- فعّل **HTTPS** واستخدم اسم نطاق فعلي.
- عدّل `.env` لإضافة `COOKIE_SECURE=true` و `PUBLIC_SITE_URL=https://your-domain.example`.
- حافظ على ملف `.env` وقاعدة البيانات خارج أي مجلد عام، واحتفظ بنسخ احتياطية آمنة من `data/bookings.sqlite3`.
- استعمل قرصًا ثابتًا (Persistent Disk) لقاعدة البيانات؛ نظام الملفات المؤقت قد يمسح الطلبات.
- أضف أداة مكافحة الرسائل المزعجة أو حماية WAF وحدود إرسال مركزية على الخادم العام.
- خدمة SMTP تحتاج حسابًا وتفعيلًا من المزود. الرسائل إلى واتساب **يدويًا بعد الضغط على زر التواصل**، وليست رسائل تلقائية عبر WhatsApp Business API.
- لعمليات واسعة النطاق، يُنصح بنقل قاعدة البيانات إلى PostgreSQL / Supabase وتفعيل أدوات مراقبة ونسخ احتياطي.

## 6) حماية البيانات
أرقام الهواتف والطلبات بيانات شخصية: حدّد من يستطيع الدخول، لا تشارك CSV مع غير المخولين، احذف البيانات عند انتهاء الحاجة وفق سياسة الاحتفاظ والخصوصية المعتمدة. أضف سياسة خصوصية للموقع قبل نشره علنًا. `setup.py` يجعل كلمة المرور آمنة نسبيًا مع PBKDF2، والجلسات موقعة، وطلبات تعديل الإدارة تحتاج CSRF token. يلزم مراجعة أمنية واختبارات وتحضير بنية إنتاج مناسبة قبل اعتماد المشروع تجاريًا.

## 7) الملفات
- `app.py`: API واستقبال الطلبات وتسجيل الدخول ولوحة التحكم والتنبيه بالبريد.
- `setup.py`: إعداد البريد وكلمة المرور ومفتاح الجلسة.
- `static/index.html`: الموقع الأساسي مع نموذج يرسل للخادم.
- `static/admin.html`: لوحة التحكم.
- `static/login.html`: تسجيل دخول الإدارة.
- `.env.example`: نموذج إعدادات فقط. الملف السري `.env` غير مضمن.
- `data/`: مكان قاعدة البيانات عند أول تشغيل (المشروع الموزع لا يحتوي طلبات عملاء).

**حالة التسليم:** نظام Backend مكتمل قابل للتشغيل محليًا، لكن **لم يُنشر ولم يُربط ببريد حقيقي** لأنه يحتاج حسابات الاستضافة والبريد وبياناتها من مالك المشروع.

### تشغيل أسهل على ويندوز
يمكن النقر مرتين على `START_WINDOWS.bat` إذا كان Python مثبتًا. عند أول تشغيل تُثبت المكتبات (يحتاج اتصال إنترنت)، ويُطلب بريد الإدارة وكلمة المرور، ثم تُفتح صفحة الموقع في المتصفح. لا تغلق نافذة الأوامر أثناء تجربة النظام محليًا.
